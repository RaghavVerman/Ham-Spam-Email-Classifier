# Ham-Spam-Email-Classifier
Developed a machine learning-based email classifier to automatically detect spam (unwanted) and ham (legitimate) emails. The system utilizes Natural Language Processing (NLP) techniques for text preprocessing—tokenization, stopword removal, and TF-IDF vectorization. Two models were implemented and evaluated:

Multinomial Naive Bayes (MNB): Chosen for its efficiency and strong performance on text data, particularly where feature independence is assumed.

Logistic Regression (LR): Implemented as a linear baseline for comparison, leveraging probabilistic interpretation and ease of regularization.

Both models were trained and tested on the popular SMS Spam Collection Dataset, achieving high accuracy, precision, and recall. This classifier can serve as the foundation for more robust email filtering systems and demonstrates practical applications of AI/ML in cybersecurity and productivity tools.
